APPLICATION LEMONADE

Une petite application Android permettant de préparer une citronnade en appuyant sur les images.

## Fonctionnement

1. Choisir un citron dans l'arbre.
2. Appuyer entre 2 et 4 fois sur le citron pour le presser.
3. Boire la citronnade.
4. Appuyer sur le verre vide pour recommencer.

## Technologies utilisées

- Kotlin
- Jetpack Compose
- Material 3
- Android Studio

## Lancer l'application

1. Télécharger ou cloner le projet.
2. Ouvrir le dossier dans Android Studio.
3. Attendre la synchronisation Gradle.
4. Lancer l'application sur un émulateur ou un téléphone Android.

Le SDK minimum requis est Android 7.0 (API 24).
